External Accounts

RigPi SDR works with several optional third-party services that extend its capabilities. Each service requires a free or low-cost account. This page describes what each service does and how to set it up.

RigPi Elmer Service

The hosted RigPi Elmer Service provides Ask Elmer answers, Elmer Control command interpretation, and live-caption translation. A ChatGPT subscription, OpenAI account, and personal OpenAI API key are not required.

Connect this RigPi

1. Sign in to RigPi with an administrator account.

2. Open SETTINGS > Accounts > Edit >Account Editor and locate RigPi Elmer Service.

3. Click Configure, enter a name for the station, and have the displayed six-character code approved by the RigPi Elmer administrator. It can take up to 24 hours for approval to be granted.  RigPi checks the approval automatically.

4. When Connected appears, use View Usage to see this station's allowance and aggregate activity.

Security: The protected station credential is stored locally and is never displayed in the browser. Disconnect revokes it immediately. After a Factory Reset, connect the RigPi again.

See Set Up Ask Elmer, Elmer Voice and Elmer Control for complete operating instructions, examples, privacy information, and troubleshooting.

Cloudflare Tunnel

Cloudflare Tunnel provides secure remote access to RigPi SDR from anywhere on the internet — without opening ports in your router or exposing your home IP address. Traffic is encrypted end-to-end through Cloudflare's global network.

RigPi SDR is pre-configured to publish two URLs through Cloudflare Tunnel:

•sdr.rigpi.org — the main SDR panadapter and radio control interface

•sdr8001.rigpi.org — direct access to SDR instance on port 8001

Why Use Cloudflare Tunnel?

•No port forwarding required in your router

•Your home IP address is never exposed

•Works through carrier-grade NAT and IPv6-only connections

•Free tier is sufficient for RigPi SDR use

Setting Up Cloudflare Tunnel

1.Create a free account at cloudflare.com.

2.Add a domain to your Cloudflare account, or use Cloudflare's free trycloudflare.com subdomain for testing.

3.In the Cloudflare dashboard, go to Zero Trust → Networks → Tunnels and click Create a tunnel.

4.Choose Cloudflared as the connector type and give the tunnel a name (e.g., rigpi).

5.Copy the tunnel token provided by Cloudflare.

6.On RigPi, install and configure the cloudflared connector using the token. Enter the following commands in an SSH terminal:

curl -L https://pkg.cloudflare.com/cloudflare-main.gpg | sudo tee /usr/share/keyrings/cloudflare-main.gpg >/dev/null

sudo apt install cloudflared

sudo cloudflared service install <your-token>

7.In the Cloudflare tunnel dashboard, add public hostnames pointing to http://localhost:80 for the main interface and http://localhost:8001 for the SDR instance.

8.Save the configuration. RigPi SDR is now accessible remotely via your Cloudflare hostname.

Note: The Cloudflare free tier supports unlimited tunnels and bandwidth for personal use. A paid plan is not required for RigPi SDR.

Pushover

Pushover delivers real-time push notifications from RigPi SDR to your iPhone, Android, or desktop. RigPi SDR uses Pushover to alert you to events such as new DX spots matching your filters, propagation changes, or system alerts.

Why Use Pushover?

•Instant alerts on your phone when a wanted DX station is spotted

•Works when you are away from the radio

•One-time purchase of $5 per platform (iOS or Android); no subscription required

Setting Up Pushover

1.Create a free account at pushover.net.

2.Note your User Key shown on your Pushover dashboard after logging in.

3.Create an application in the Pushover dashboard: click Create an Application/API Token, give it a name (e.g., RigPi SDR), and save. Note the API Token.

4.Install the Pushover app on your iPhone or Android device. A 30-day free trial is included; after that, a one-time $5 purchase unlocks the app permanently.

5.In RigPi SDR Settings, enter your Pushover User Key and API Token in the Notifications section.

6.Use the Test button in RigPi SDR to confirm notifications are working.

Note: Your User Key and API Token are sensitive. Do not share them. They can be regenerated from the Pushover dashboard if compromised.

QRZ

QRZ is the world's largest amateur radio callsign database. RigPi SDR uses the QRZ XML API to look up callsign information including the operator's name, address, grid square, country, DXCC entity, LoTW status, and photo. This information appears in the ELMER Workability Index panel when you look up a DX station.

QRZ Account Levels

QRZ offers several account levels. The XML API used by RigPi SDR requires a QRZ XML Subscription:

•Free account — callsign page access via browser only; XML API not included

•QRZ XML Subscription — required for RigPi SDR integration; provides programmatic callsign lookup. Available at qrz.com/page/xml_data.html.

Note: Without a QRZ XML Subscription, callsign lookups in the ELMER Workability Index will return limited data. Grid square information used for path calculations may not be available.

Setting Up QRZ

1.Create or log in to your account at qrz.com.

2.Purchase a QRZ XML Subscription if you do not already have one.

3.In RigPi SDR Settings, enter your QRZ username and password in the QRZ section. RigPi SDR uses these credentials to obtain a session key from QRZ at lookup time; your password is stored locally on RigPi and is never transmitted to third parties.

4.Click any DX callsign in the ELMER Workability Index to test the lookup. The operator's name, location, grid square, and photo (if available) will appear in the QRZ panel.

Note: After a Factory Reset, QRZ credentials must be re-entered in Settings. See System Settings for more information.

Google API Key (Gmail)

RigPi SDR uses a Google API key to send outgoing email via Gmail. This is used when you email a Workability Index report to a DX station directly from the ELMER panel. The key authorizes RigPi to send mail through your Gmail account using the msmtp mail transfer agent.

Setting Up Google API Access

1.Sign in to your Google account and go to console.cloud.google.com.

2.Create a new project (e.g., RigPi SDR).

3.Enable the Gmail API for the project: go to APIs & Services → Library, search for Gmail API, and click Enable.

4.Go to APIs & Services → Credentials and click Create Credentials → API Key. Copy the key that is generated.

5.In RigPi SDR Settings, paste the API key into the Google API Key field.

6.Send a test WI report from the ELMER panel to confirm email delivery.

Warning: Your Google API Key is sensitive. Restrict it in the Google Cloud Console to the Gmail API only to limit exposure if the key is ever compromised. After a Factory Reset, the key must be re-entered in Settings.

Note: Google may require you to configure an OAuth consent screen for the project. For personal use, setting the app to Internal or leaving it in testing mode with your own account as a test user is sufficient.
