Account

Account Management

RigPi supports multiple user accounts with different access levels. This page covers account requests, approval, settings, and administration.

For Guests & New Users

Requesting a New Account

If you do not have a RigPi account, you can request one from the login page.

1

Go to the RigPi login page. Below the Login button, click Request an Account.

2

Fill in the request form. Required fields are marked with an asterisk (*):

 

•Callsign — your amateur radio callsign

•Username — your desired login name (no spaces; lowercase recommended)

•Password — your desired password

•First & Last Name

•Email Address — used for approval notifications

Optional fields (phone, grid square, address) are helpful for the administrator to verify your identity.

3

Click Send Account Request. The administrator will receive a notification via Pushover with your information.

4

You will see a confirmation message. Your account is created immediately but is pending approval — you cannot access RigPi until the administrator approves it.

 

Note: Your username must be unique. If you see an error that the username is taken, choose a different one and resubmit.

Account Approval Pending

After submitting your request, if you try to log in you will see an Account Approval Pending page. This is normal — your account exists but has not yet been approved by the administrator.

The page shows the administrator’s email address so you can follow up if needed. Once approved, you will be able to log in normally. Contact the administrator directly if you have not heard back within a reasonable time.

First Login After Approval

Once your account is approved you can log in with your username and password. On first login:

•You will be taken to the main RigPi interface with your assigned SDR and radio.

•Your SDR will initially be set to a dummy (software) radio. The administrator can assign you a real SDR device if hardware is available.

•You can select an available SDR device from the Device dropdown in the SDR panel. Devices in use by other users are shown dimmed.

Managing Your Account Settings

To update your account information, go to Settings → Accounts. You will be taken directly to your own Account Editor. You can update:

•Callsign, name, address, email, phone, grid square

•Password

•QRZ username and password for callbook lookups

•SDR host settings (if you access RigPi remotely)

•WSJT-X and Fldigi log sync settings

Note: Access Level is set by the administrator and cannot be changed by regular users.

For Administrators

Reviewing Account Requests

When a guest submits an account request, you receive a Pushover notification with:

•Callsign and username

•Full name and email address

•Phone number and grid square (if provided)

•City and state

•Instruction: “Set Access Level to 2 to approve”

The account is created in the database with Access Level 9 (pending). The user cannot access RigPi until you approve it. Account requests are also logged to /var/www/html/my/account_requests.log.

Approving an Account

1

Go to Settings → Accounts. You will see the full user list including pending accounts (Access Level 9).

2

Click the edit button next to the pending user to open their Account Editor.

 

 

 

3

Review the user’s information. Using the Access dropdown, change their Access Level from 9 to 2 (Standard — no Account or System Settings access).

 

 

 

 

4

Set the SDR Host field if needed (e.g., http://rigpi5.local/sdr5). This is normally set automatically by the provisioning system.

 

 

 

 

5

Click the Save button. The SDR provisioning system will automatically:

 

6

Send the user an email with their login credentials. RigPi does not send approval emails automatically.

 

 

•Create an SDR instance config file (instance_800x.json)

•Start a dedicated dummy SDR service (sdr_web@800x)

•Start a dedicated dummy rigctld instance

•Add an nginx route for /sdrN

•Set the user’s SDRHost in the database

6

Send the user an email with their login credentials. RigPi does not send approval emails automatically.

Tip: Provisioning runs in the background. Check /var/log/rigpi-provision.log to confirm it completed successfully.

Note: To reject a request, simply delete the user from the Accounts list.

Level

Name

Description

1

Admin

Full access — all settings, all accounts, system control

2

Normal user — no Account or System Settings; can use SDR and radio

SDR Provisioning

Each user account has a dedicated SDR instance assigned based on their user ID (uID):

•Port: 8000 + uID   (e.g., uID 5 = port 8005)

•rigctld port: 4530 + uID × 2   (e.g., uID 5 = port 4540)

•nginx path: /sdrN where N = uID

•SDR Host: http://rigpi5.local/sdrN

New accounts are provisioned with a dummy SDR and dummy radio. Users can select a different physical SDR device from the Device dropdown if one is available and not in use by another user.

To manually re-run provisioning for a user:

sudo /home/pi/sdr_web/provision_sdr_user.sh <uID> <username>

Provisioning log: /var/log/rigpi-provision.log

Managing All Users

The Accounts page (Settings → Accounts) shows all users with their callsign, access level, username, name, location, and last visit time.

•Edit button — open the Account Editor for that user

•Delete button — permanently remove the account

•Plus button — add a new account manually (admin only)

Warning: Deleting an account is permanent and cannot be undone. The user’s SDR instance and configuration files are not automatically removed. Stop the service manually if needed:

 

systemctl stop sdr_web@800x
