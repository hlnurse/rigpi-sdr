RigPi 5 Software Defined Radio Architecture

System Architecture

ELMER runs as a Python/Flask web server on the Raspberry Pi 5, integrated with the RigPi Station Server platform. The browser client communicates via WebSocket (spectrum data), WebRTC (audio), and REST API (control).

Browser
  ├── WebSocket /ws/spectrum  → Real-time FFT/waterfall data
  ├── WebRTC audio            → Demodulated audio stream
  └── REST API /api/*         → Control, state, spots, workability
Flask/Gevent Server (sdr_web_server_minimal.py)
  ├── SoapySDR Engine         → Hardware abstraction
  ├── FFT/DSP Pipeline        → NumPy demodulation
  ├── RigPi DB (MariaDB)      → User settings, spots, log
  └── External APIs           → NOAA, PSKReporter, QRZ, etc.

Hardware Support

AirSpy HF+ (Port 8001)

•Driver: airspyhf via SoapySDR

•Coverage: 9 kHz – 31 MHz, 60–260 MHz

•Sample rates: 192 kHz – 912 kHz

•Measured MDS: −136 dBm (spec −140 dBm)

•Serial: Configured in config/instance_8001.json

RTL-SDR / Nooelec SMART (Port 8002)

•Driver: rtlsdr via SoapySDR

•Coverage: 500 kHz – 1.75 GHz (HF with direct sampling)

•HF direct sampling: Set device_args to direct_samp=2 (high HF) or direct_samp=1

•Sample rates: 250 kHz – 2.4 MHz

SDRplay RSP-ST

•Integration: SDRConnect 1.0.8 WebSocket API

•Connection: Via Remote tab → SDRConnect section

•Port: Configurable in SDRConnect settings

External Data Sources

NOAA Space Weather Prediction Center

•Solar flux (SFI): https://services.swpc.noaa.gov/json/solar-cycle/observed-solar-cycle-indices.json

•K-index: https://services.swpc.noaa.gov/products/noaa-planetary-k-index.json

•Cache: 15 minutes

•No authentication required

PSKReporter

•URL: https://retrieve.pskreporter.info/query

•Usage: Query stations hearing the DX callsign in the last hour

•Parameters: senderCallsign=, flowStartSeconds=-3600

•Returns: XML with receiver callsigns, locators, frequencies, modes

•No authentication required

•Rate limit: Use sparingly — 1 query per workability fetch

ARRL DX Bulletin

•Archive: http://www.arrl.org/w1aw-bulletins-archive-dx

•Content: http://www.arrl.org/w1awbulletinsdxissue?issue=YYYY-MM-DD&code=ARLDxxx

•Format: Text within ZCZC ... NNNN markers

•Cache: 1 hour

•No authentication required

QRZ XML API

•URL: https://xmldata.qrz.com/xml/current/

•Authentication: QRZ username and password (stored in RigPi Users table)

•Returns: Grid square, name, address, LoTW status, photo URL, biography

•Credentials: Stored in station.Users table fields qrzUser, qrzPWD

•Subscription: QRZ XML access requires a QRZ account (free or paid)

Logbook of the World (LoTW)

•User list: https://lotw.arrl.org/lotw-user-activity.csv

•Format: CALLSIGN,DATE,TIME — 230,000+ entries

•Cache: Downloaded to /home/pi/sdr_web/lotw_users.csv

•Update: Download periodically with:

curl -o /home/pi/sdr_web/lotw_users.csv https://lotw.arrl.org/lotw-user-activity.csvsudo systemctl restart sdr_web@8001

•Loaded into memory at server startup for instant O(1) lookups

DXSummit

•API: http://www.dxsummit.fi/api/v1/spots?dx_calls=CALL&limit=100

•Returns: JSON array of spots with frequency, time, spotter, info

•Usage: Activity window analysis — typical operating hours and bands

•No authentication required

WA7BNM Contest Calendar

•RSS: https://www.contestcalendar.com/calendar.rss

•Returns: RSS 2.0 with contest name, date/time, description

•Updates: Daily

•No authentication required

•Credit: Bruce Horn WA7BNM — https://www.contestcalendar.com

DX Cluster / RigPi Spot Manager

•Source: RigPi MariaDB station.Clusters table

•Update: System → Update Cluster List button (fetches from dxcluster.info)

•Count: 900+ clusters worldwide

Workability Index Algorithm

The scoring engine (elmer_workability.py) computes a weighted composite score:

WEIGHTS = {
    'pskreporter': 0.20,  # Real-time propagation evidence
    'band_muf':    0.18,  # Band usability for path
    'grayline':    0.15,  # Solar terminator alignment
    'solar':       0.15,  # SFI and K-index
    'bulletin':    0.12,  # DXpedition confirmed active
    'antenna':     0.10,  # Beam alignment
    'cluster':     0.10,  # Recent spot activity
}

MUF Estimation

Band MUF is estimated using a simplified formula based on solar flux (SFI) and path distance:

•Short paths (<500 km): Near-vertical incidence, lower MUF

•Medium paths (500-8000 km): Standard ionospheric reflection

•Long paths (>8000 km): Multiple hops, reduced MUF

Grayline Score

Sun elevation is calculated at both path endpoints:

•Terminator zone (−6° to +6° elevation): Score 1.0

•Twilight zone (−12° to +12°): Score 0.7

•Night (< −18°): Score 0.4

•Full daylight: Score 0.2

Activity Window Analysis

DXSummit spots are parsed for UTC hour distribution. The algorithm finds the longest contiguous window of activity (allowing 1-hour gaps) to determine typical operating hours.

Award Tracking

The /api/log_lookup endpoint computes award status from the Logbook:

DXCC

Counts unique DXCC entity numbers. Confirmed = LoTWReceived='Y' OR QSL_R='Y' OR eQSLReceived='Y'.

WAC (Worked All Continents)

Checks His_Continent for all 6 continents: AF, AN, AS, EU, NA, OC, SA.

WAZ (Worked All Zones)

Checks CQZone for all 40 CQ zones.

WAS (Worked All States)

Checks His_State for US contacts (His_Country LIKE '%United States%').

Multi-Instance Configuration

Each SDR instance has its own config file:

// /home/pi/sdr_web/config/instance_8001.json
{
  "port": 8001,
  "device_driver": "airspyhf",
  "device_serial": "c8529780ea4946c7",
  "rigport": 4532,
  "label": "AirSpy HF+ 1",
  "rigpi_url": "http://localhost",
  "device_args": ""
}

device_args supports SoapySDR key=value pairs, e.g. direct_samp=2 for RTL-SDR HF direct sampling.

Cloudflare Tunnel

ELMER is accessible remotely via Cloudflare Tunnel:

•https://sdr.rigpi.org — Port 8001 (AirSpy HF+)

•https://sdr8001.rigpi.org — Port 8001 alternate

Configure in /etc/cloudflared/config.yml. Enable/disable in RigPi System settings.

Note: HTTPS via Cloudflare enables browser clipboard API for formatted copy/paste from the Workability report.

sudo /home/pi/sdr_web/factory_reset.sh

Resets all SDR settings, clears user configs, resets passwords:

•admin: 7388

•guest1: 7389

•guest2: 7390

cp /home/pi/sdr_web/index.html /home/pi/sdr_web/index.html.backup
