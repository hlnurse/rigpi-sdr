RigPi-SDR FT8 panel layering fix

This package closes the thin paint seam between the decoder status bar and
the spot-table header. Version 4 removes the Chromium sticky table header:
the column titles are now outside the vertically scrolling decode table, and
horizontal scrolling is synchronized. Version 5 restores a compact 656-pixel
column layout. It includes the preceding manual FT8/FT4 decoder-control update.

On RigPi:

  cd /path/to/deployed/pi/sdr_web
  sudo bash install_ft8_panel_layering.sh

Then force-reload the RigPi-SDR browser page.
