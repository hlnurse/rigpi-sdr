Set Up Ask Elmer, Elmer Voice and Elmer Control

Elmer adds three related capabilities to RigPi:
 

Feature

Purpose

Ask Elmer

Answers RigPi and amateur-radio questions using an indexed technical library, approved live station and internet data, deterministic tools, and information supplied by the operator. Sources used for an answer are identified in its References section.

Elmer Voice

Accepts spoken questions and commands, reads answers aloud, and can provide live transcription and translation.

Elmer Control

Provides a compact command drawer in the Tuner and Keyer windows for safe radio, CW, macro, scanning, and recording actions.

Requirements

•An internet connection.

•A current RigPi release containing Elmer.

•A paired RigPi Elmer Service connection.

•For voice input, microphone permission and a secure HTTPS RigPi connection. A local secure browser context may also work.

No OpenAI setup is required. RigPi users do not need a ChatGPT subscription, OpenAI account, or personal API key. RigPi.net supplies the hosted service through the station's Elmer plan or beta allowance.

Connect the RigPi Elmer Service

1.Sign in to RigPi with an administrator account.

2.Open Settings > Accounts > User Settings.

3.Locate RigPi Elmer Service and select Configure.

4.If the station is not connected, enter a recognizable station name.

5.Provide the displayed six-character approval code to the RigPi Elmer administrator. Approval may take up to 24 hours.

6.You may leave the page and return later. RigPi checks the request again and displays Connected after approval.

Select View Usage to see the station plan, allowance, questions, tokens, response timing, and voluntary feedback totals. Usage is shared by the accounts on that physical RigPi.

Disconnect immediately revokes the protected station credential. Ask Elmer, hosted voice processing, and cloud command interpretation will stop until the station is paired again.

Use Ask Elmer

1.Open Help > Ask Elmer.

2.Enter a question in everyday language. Press Enter to ask; use Shift+Enter for a new line. To ask by voice, tap Elmer PTT, speak after the tone, then tap it again when finished. No wake phrase is required.

3.Elmer searches the RigPi knowledge collection and, when appropriate, station-local live services such as QRZ, the onboard FCC database, repeater data, or shortwave schedules.

4.Use the speaker control to turn spoken answers on or off. The animated voice indicator shows when Elmer is listening or speaking.

5.Use Copy to copy the formatted answer. Links and approved images remain available in the displayed answer.

6.Rate the answer from 1 through 10 and optionally explain why. Submitted feedback helps improve RigPi.

Example questions include:

•How do I configure an IC-7300 for remote audio and CAT control?

•How do I set up remote CW keying?

•Start CW simulator

•Show me a photograph and biography for W6HN

•Show K8AJS on a map

•Find all ham clubs within 40 miles of ZIP 44691

•Show all Extra-class hams within 10 miles of Wooster, Ohio

•What shortwave stations are broadcasting in Spanish now?

•What are the W8WOO repeater frequencies?

References marked Official Help are the preferred source for current RigPi operation. Community posts and contributed files may describe older releases; Elmer identifies uncertainty and conflicting procedures when the evidence permits.

Ask Elmer information sources

Ask Elmer selects sources according to the question. A normal answer uses only the relevant items and identifies them in its References section. Availability of live sources depends on the signed-in RigPi account, configured external accounts, station connection, and internet access.

Indexed knowledge library

Source

Information provided

Official RigPi Help

Current operating instructions and the preferred authority for RigPi features and settings.

RigPi GitHub

RigPi source code, README material, releases, issues, issue discussions, and other project documentation.

Hamlib GitHub

Hamlib source code, radio backends, documentation, releases, issues, issue discussions, and wiki material.

WSJT-X

The official WSJT-X 3.0 User Guide plus WSJT-X source, documentation, releases, and issue discussions.

RigPi Groups.io

Community support messages, discussion threads, and contributed files. These may describe older RigPi versions and are treated as community evidence.

SIGIDWiki Amateur Radio Signals

Community-maintained descriptions and examples of amateur-radio signal types and digital modes.

47 CFR Part 97

The current Amateur Radio Service rules imported from the official eCFR developer service.

Live, local, and calculated sources

Source

Information provided

Operator and conversation context

The current question, an attached image, recent Ask Elmer exchanges, and relevant signed-in station details supplied by RigPi.

RigPi station databases and live services

Selected radio, station and user settings, radio status and readback, rigctld and rotctld state, CW/keyer runtime, serial-device availability, browser-audio status, and other read-only diagnostic observations.

RigPi frequency intelligence

BandActivity customary operating ranges and calling frequencies, BandPrivileges license and emission privileges, and the operator's configured country, IARU region, and license class. Activity entries are guidance rather than exclusive allocations or permission to transmit.

RigPi local logbook

Previous contacts with a requested callsign when the question calls for logbook history.

QRZ XML, HamQTH XML, and the RigPi onboard FCC database

Callsign identity, license and location details, grid and coordinates when available, plus QRZ biography, photographs, and station information when authorized by the configured account.

NCVEC Question Pool Committee

Current Technician, General, and Amateur Extra question pools, answer keys, diagrams, and syllabus topics used by Elmer's study questions and simulated exams.

HearHam

Cached repeater-directory records and approximate transmitter-site coordinates.

ILGRadio and EiBi

Cached shortwave broadcast schedules. Licensed ILGRadio data remains for local RigPi use and is not redistributed; EiBi provides fallback schedule coverage.

Open-Meteo

Current, forecast, and historical gridded weather plus supporting forecast data used for operating and antenna-safety questions.

NOAA Space Weather Prediction Center

Solar-flux, geomagnetic, and planetary K-index forecast information used in propagation guidance.

DX Summit

Recent cluster spots used to find observed path and time patterns. Spots are reports, not confirmed contacts or propagation guarantees.

WorldFactbook.io

Current country profiles for international callsign and country questions.

Natural Earth and OpenStreetMap

Country outlines, map tiles, place lookup, and geographic context. Callsign markers use callbook coordinates when available; inferred or approximate locations are identified.

RigPi Ham Tools

Deterministic antenna, wavelength, transmission-line, power, impedance, unit-conversion, and related amateur-radio calculations.

The language model is the explainer, not the evidence. It organizes and explains the retrieved material. Official rules and current RigPi Help outrank community reports; live observations are timestamped or described as snapshots, and customary activity information is not presented as regulatory authorization.

CW practice and contest simulators

Ask Elmer includes browser-based CW receiving practice. Enter CW simulator to resume the last-used exercise, or ask for a specific exercise by name. Use the Practice selector to move between exercises without losing the selected character speed, spacing speed, or band conditions.

Practice mode

What it sends

CW QSO

Natural, varied contacts containing callsigns, signal reports, names, locations, rigs, power, antennas, and closing exchanges.

Callsigns

Random amateur-radio callsigns for focused copying practice.

Random 5-character groups

Five groups of five mixed letters and numbers.

Sweepstakes Contest

Serial number, precedence, callsign, check, and ARRL/RAC section.

ARRL Field Day

Operating class and ARRL/RAC section. Field Day does not use an RST in its exchange.

DX Pileup

A DX station and overlapping callers, including partial-call requests, occasional callers transmitting at the wrong time, and selectable pileup intensity.

CQ WW

RST and CQ zone.

CQ WPX

RST and a progressive serial number.

ARRL International DX

W/VE stations copy RST and transmitter power from DX stations; DX stations copy RST and state or province from W/VE stations.

1.Select the exercise, character speed, spacing speed, and band conditions. A spacing speed below the character speed provides Farnsworth practice.

2.With the copy box focused, press Enter to play the CW.

3.Type everything copied and press Enter to check it.

4.Press Enter again for the next callsign or exchange, then press Enter once more to play it.

Clean, light, and busy conditions add progressively stronger recorded receiver noise, off-frequency QRM, and fading. DX Pileup provides separate light, moderate, and heavy caller settings. The selected exercise and settings are remembered for the signed-in callsign in that browser.

Practice is safe and self-contained. The simulator generates CW audio in the browser. It does not key the radio, assert PTT, change the station, or require an SDR audio connection.

Use Ham Tools

Ask Elmer includes deterministic amateur-radio calculators and operating references. RigPi Ham Tools performs the numerical work and Elmer explains the result, so the answer is based on the displayed inputs and formula rather than an estimated language-model calculation.

Examples include:

•How long is a dipole for 14.2 MHz?

•Design a quarter-wave ground-plane antenna for 146.52 MHz

•Give me starting HB9CV dimensions for 144.3 MHz

•Design a 10-turn axial helix for 2.4 GHz

•What is the wavelength at 7.2 MHz?

•Estimate the loss in 75 feet of LMR-400 at 146 MHz with 100 watts

•What is the VSWR with 100 watts forward and 4 watts reflected?

•Using Ohm's law, what current flows with 13.8 volts and 50 ohms?

•Convert 37 dBm to watts

•What is the output after 3 dB loss from 100 watts?

•Spell W6HN phonetically

•What does QSY mean?

Use calculated antenna dimensions as starting values. Element diameter, insulation, installation height, nearby objects, and construction details affect resonance and impedance. Cut elements slightly long and make final adjustments with an antenna analyzer. Coax-loss results use representative cable data for planning; confirm the exact manufacturer's specifications and allow for connector, adapter, weather, age, moisture, and VSWR losses.

Use Elmer Voice

Browser requirements: Use a current browser, an HTTPS RigPi address, and allow microphone access for the RigPi site. Elmer voice input uses hosted speech recognition and works in supported desktop and mobile browsers, including current Chrome and Safari. Typed Ask Elmer questions and Elmer Control commands remain available when voice is unavailable.

Chrome local-LAN microphone override: HTTPS remains the preferred method. If Chrome blocks microphone access to a trusted local RigPi address, open chrome://flags/#unsafely-treat-insecure-origin-as-secure. Enable Insecure origins treated as secure, enter the complete origin—normally http://rigpi5.local—and relaunch Chrome. Include the port when one is present. Reopen RigPi and grant microphone permission. Use this exception only for a trusted RigPi on the local network; it does not encrypt HTTP traffic and is not a substitute for HTTPS remote access.

1.Open Ask Elmer or the Elmer Control drawer and tap Elmer PTT.

2.Allow microphone access when the browser asks. The permission belongs to the RigPi site and browser being used.

3.After the tone, speak normally, then tap Elmer PTT again to finish. The button is push-to-talk; no wake phrase is needed.

4.Review any frequency or other safety-sensitive value that RigPi asks you to confirm. In Elmer Control, tap Affirm or Cancel, press Enter for the default Affirm action, or use Elmer PTT to speak the response.

5.Use the speaker control to enable or disable spoken playback. When enabled, Elmer reads answers, proposed actions, and results in an AI-generated voice.

Elmer automatically recognizes supported languages, searches using English source material, and answers in the speaker's language. Elmer Control also accepts approval words in the language used for the command. Live captions can transcribe received audio and translate it to a selected language.

Voice audio is sent to the hosted Elmer service only between the two Elmer PTT taps or while live captions are active. The listening indicator and tone show when capture begins. Turn off live captions when they are not needed.

Use Elmer Control

Open the Elmer Control drawer from the side tab in the main Tuner or Keyer window. Type a command and select Run, or tap Elmer PTT, speak after the tone, and tap it again when finished. Typed and spoken commands use the same control path; no wake phrase is required.

When a command requires approval, Elmer displays the proposed action before changing the station. With spoken results enabled, Elmer reads the proposal first and the approval timer starts after the reading finishes. Respond with Affirm or Cancel, press Enter to choose the default Affirm button, or tap Elmer PTT and speak the response. Elmer then carries out the approved action and verifies the result when possible.

Examples include:

•Connect radio and power on

•Disconnect radio

•Tune to FT8 on 20 meters

•Tune radio 1 to 14.025 MHz CW

•Set mode to CW and bandwidth to 500 Hz

•Split up 5 kHz

•Split down 2 kHz

•Split off

•Restore the previous frequency and mode

•Swap VFOs

•Copy VFO A to VFO B

•Set volume to 20 percent

•Set microphone level to 50 percent

•Set RF gain to 40 percent

•Set CW speed to 22 words per minute

•Put CQ CQ DE W6HN in the CW buffer

•Run macro CW BW 500 HZ from bank 2

•Scan shortwave broadcasts in Spanish and stop on a signal

Use the up/down triangles or keyboard Up/Down arrows to recall previous commands. During a supported scan, Space stops on the current frequency; press Space again to resume.

Operator remains in control. Elmer uses allowlisted station actions, confirms sensitive changes, verifies results when possible, and does not treat ordinary text as permission to transmit. Check the selected radio, frequency, mode, bandwidth, power, antenna, and operating privileges before transmitting.

Radio and browser troubleshooting

Symptom

What to check

Elmer reports that radio control is unavailable.

Open the Tuner and connect the selected radio first. Confirm that normal RigPi tuning works, then repeat the command.

The microphone is unavailable.

Use HTTPS, check the browser's microphone permission for the RigPi site, reload the page, and select the microphone again. For trusted local HTTP access in Chrome, use the documented Insecure origins treated as secure override.

The wrong language is recognized.

Check the voice-language selection. Automatic recognition usually works best when the command contains a complete phrase and a clearly spoken frequency.

A spoken frequency is uncertain.

Elmer should request confirmation. Cancel the change if the displayed frequency is not exactly what you intended, then type the command.

The allowance is exhausted.

Open View Usage. During the beta, contact the RigPi Elmer administrator; production plans and refills are managed through RigPi.net.

References open the wrong page.

Reload Ask Elmer and try the reference again. Official Help references resolve locally on the RigPi.

Privacy and account scope

•The station credential is stored on the RigPi and is never displayed in the browser.

•QRZ and HamQTH passwords remain on the RigPi. Only facts requested for an answer are sent to the hosted Elmer service.

•Station statistics contain operational totals; the station statistics page does not display question, answer, or feedback-comment text.

•Answer feedback is optional. The feedback notice explains what is submitted before it is sent.

After a Factory Reset

The Elmer station credential is not restored from the RigPi user database backup. Sign in as administrator and pair RigPi Elmer Service again. Reconnect other external services whose protected credentials were not restored.
